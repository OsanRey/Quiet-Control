# Разработка и обновления upstream

Quiet Control основан на [Satelite](https://github.com/zn0wii/satelite-proxy).
Исходный upstream baseline — `1b33c42f5a61fdadfdb23e7298be406ecf5c0707`.
Собственные изменения следует вести в отдельных ветках. Отменённый этап 4.6
не входит в текущую базу; не переносите его случайным merge всех локальных веток.

```powershell
git remote add upstream https://github.com/zn0wii/satelite-proxy.git # если отсутствует
git fetch upstream --tags
git switch -c integration/upstream-YYYY-MM-DD
# Выберите конкретный upstream-коммит и изучите diff перед merge/cherry-pick.
```

Перед интеграцией сохраните контрольную точку. Особое внимание: CSP, привилегированный
helper, доверие к сетевым ядрам, локальный API, TUN cleanup и сохранение выбора узла.
После интеграции выполните сборку и целевые тесты; сетевые изменения проверяйте
в изолированной VM. Не отправляйте изменения в upstream без отдельного намерения.

Публичный репозиторий получает отдельный `origin`; адрес upstream сохраняется.
Не используйте force push для существующих удалённых веток. Не публикуйте все
локальные refs или резервный bundle: они содержат исследовательскую историю,
а не только предназначенную к публикации ветку.

Не коммитьте подписки, runtime store, отчёты с секретами, HWID, частные QA ISO,
кеши и результаты сборки. При находке секрета в истории публикация останавливается
до очистки истории; одного удаления из текущего дерева недостаточно.
