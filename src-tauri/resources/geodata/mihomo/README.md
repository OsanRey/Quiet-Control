# Preserved upstream data snapshot

`country.mmdb` and `geosite.dat` are unmodified build inputs inherited from
Satelite. The original snapshot script is `scripts/fetch-bundled-mihomo-geodata.sh`.
They are retained as reproducible resources, not executable VPN cores or user data.

Source project: https://github.com/MetaCubeX/meta-rules-dat
Upstream license: https://github.com/MetaCubeX/meta-rules-dat/blob/master/LICENSE
(GPLv3; copy in LICENSE.txt). These datasets are not relicensed under the
application's Apache-2.0 license. Follow upstream credits and constituent-data
terms when redistributing datasets or a complete binary distribution.

The source project documents its inputs and credits, including
Loyalsoldier/geoip and v2fly/domain-list-community. No claim that a GPL repository
notice alone clears every constituent dataset or Microsoft runtime is made.
The local research portable remains outside the public binary release.
