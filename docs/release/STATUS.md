# Статус подготовки

Основа: 8b18a7b, без отменённого этапа 4.6. Изменения уборки ограничены документацией,
Git-гигиеной, CI без публикации бинарников и проверочными сценариями.

После удаления старых артефактов выполнены восстановление pnpm dependencies по
frozen lockfile, frontend tsc/Vite и полная Rust-сборка из заново созданного target.
Контрольные проверки страницы узлов/отображения задержки пройдены.
Подробный локальный отчёт инвентаризации хранится вне публикуемого Git.

Нативный запуск новой сборки и скриншоты в VM ещё не подтверждены. Старые JSON
прогонов сохранены с их реальными статусами; успешные проверки другого этапа
не выдаются за новую приёмку. Короткий cleanup QA не должен запускать TUN или
повторять всю сетевую матрицу.

Публикация исходников пока не выполнена: ожидается нативная приёмка. GitHub CLI
авторизован владельцем аккаунта.
До push нужно повторно проверить именно публикуемую ветку и изображения.
Закрытые резервные Git bundle/QA-архивы не публикуются.

Бинарный релиз не подготовлен для публичного распространения: локальный portable
остаётся экспериментальным, Microsoft runtime snapshot требует отдельной проверки
пути распространения. Автоматическая выдача бинарных релизов по v*-тегу отключена;
workflow выполняет только проверки исходников с contents:read.

QC_CLEAN_V1 завершился до запуска приложения из-за ошибки сборки массива
аргументов PowerShell. Сохранены launcher-state/stderr и исходный неуспех.
Исправление воспроизведено на PowerShell 5.1: исходно 4 аргумента, после
скобок 3, точный путь сценария запускается, exit 0. Продукт не пересобирался.
QC_CLEAN_V2 повторяет только короткую приёмку уборки, без запуска TUN/ядер.
