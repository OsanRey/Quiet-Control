## Границы

Это проверка сборки, ресурсов и основных GUI/локальных операций в Windows VM.
Сетевые ядра и TUN не запускались; доступность провайдеров, IPv6 и полная сетевая
совместимость заново не подтверждались. Данные синтетического localhost-узла
не выдаются за работающее VPN-подключение. Основная установка не изменялась.

Публикуется только ветка release/quiet-control-source: исходная история Satelite
с отдельными коммитами подготовленного форка. Исследовательские refs, приватные
отчёты, резервные bundle, runtime snapshots, QA ISO и portable ZIP не отправляются.

Бинарный релиз не подготовлен для публичного распространения: локальный portable
остаётся экспериментальным, Microsoft runtime snapshot требует отдельной проверки
пути распространения, ядра и datasets имеют отдельные лицензионные обязательства.
Автоматические бинарные releases отключены; workflow проверяет исходники с
contents:read. Не выдавать неподписанный debug-пакет за стабильный релиз.
