# Quiet Control

Персональный форк [Satelite](https://github.com/zn0wii/satelite-proxy) для Windows 11 x64: управление VPN-узлами, подписками и выборочной маршрутизацией в компактном русском интерфейсе.

Проект экспериментальный. Здесь не заявляется стабильный публичный бинарный релиз или полная совместимость со всеми конфигурациями провайдеров.

## Возможности

- Единый раздел «Узлы»: подписки, локальные узлы, поиск, группировка, избранное, проверки задержки и явное подключение.
- Ручной, интеллектуальный и автоматический выбор; проверка и просмотр источника не должны неожиданно менять подключение.
- Quiet Control UI с Dark, Light и System, адаптацией к окну и русской локализацией.
- Режимы локального прокси, системного прокси Windows и TUN в поддерживаемых сценариях.
- Правила по приложениям и доменам, DNS, монитор соединений и журнал.
- Интеграции sing-box 1.13.18, Xray 26.3.27 и Mihomo 1.19.30 с разными ограничениями.
- Исследовательские исправления CSP, доверия к загружаемым ядрам и восстановления сетевого состояния.

## Текущее состояние

Основа — версия до отменённого этапа 4.6: исходники `8b18a7b`, продукт объединённой страницы узлов `c0ceff9`. Этап 4.6 исключён. Уборка не переносит его изменения и не перерабатывает сетевую логику.

Предыдущие этапы имеют отдельные локальные доказательства runtime. Для объединённой страницы сохранён неуспешный QA-прогон, поэтому нельзя называть её полностью принятой только по unit-тестам. После уборки нужна отдельная короткая проверка свежей сборки в VM; статус описывается в `docs/release/STATUS.md`.

## Ограничения

- Поддержка протокола ядром не означает поддержку произвольного полного клиентского JSON парсером приложения. Балансировщики, finalmask и часть нестандартных полей ограничены.
- TCP-доступность порта не подтверждает передачу VPN-трафика. Надпись «Ядро работает» также не подтверждает доступность интернета.
- Xray не получает новую интеграцию TUN в рамках этого форка. Поддержка маршрутизации зависит от ядра и определения процесса Windows.
- При неизвестном процессе или неполных данных монитор не должен выдумывать причину выхода.
- Windows 11 x64 — целевая платформа форка. Исходная кроссплатформенность Satelite не является доказательством приёмки Quiet Control на Linux/macOS.

## Сборка и развитие

См. [BUILDING.md](BUILDING.md), [CONTRIBUTING.md](CONTRIBUTING.md), [CHANGELOG.md](CHANGELOG.md).
Архитектура сохранена: `src/` — React, `src-tauri/` — Rust/Tauri, `scripts/` — сборка и проверки.

Для обновления существующей установки сначала штатно закройте приложение и сохраните **весь** её каталог данных. Не заменяйте программу при работающем TUN. Уборка исходников не изменяет установку пользователя.
